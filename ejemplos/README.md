# Ediciones reales

Las respuestas de `npm run setup` de tres AWS Student Community Days que se
hicieron con el kit. Sirven de punto de partida: copia el más parecido al tuyo,
cambia lo que haga falta y aplícalo.

```bash
cp ejemplos/chile-2026.json respuestas.json   # y edítalo
npm run setup -- --desde respuestas.json
npm run doctor
```

| Archivo | Edición | Fecha | Sede | Modalidad | Tema |
|---|---|---|---|---|---|
| `colombia-2026.json` | [Colombia](https://awsstudentcommunity.day) | 26 de junio de 2026 | Cámara de Comercio de Bogotá, Calle 26 | Presencial y online | `naranja` |
| `chile-2026.json` | [Chile](https://scdchile.cl) | 24 de octubre de 2026 | Duoc UC, Sede Maipú (Santiago) | Presencial y online | `lavanda` |
| `mexico-2026.json` | [México-CDMX](https://studentcommunitydaymexico.com) | 4 de noviembre de 2026 | Centro Histórico y Cultural «Juan de Dios Bátiz», IPN | Presencial | `#C143BC` |

Los correos de contacto son de ejemplo (`@example.com`): pon los tuyos. La
fecha de entrega de diapositivas de Colombia es la que el kit propone por
omisión; las demás fechas, sedes y redes son las de cada edición.
